# the zone

This is a visual companion to Thomas Pynchon's *Gravity's Rainbow* (1973).

## current live pages

- **glossary**: critical terms and phrases in the novel
- **reference**: bibliography and source notes

Only Glossary and Reference are available from the homepage. The homepage itself contains the section index and the episode word-count plot.

## forthcoming pages

Episodes, Language, Network, Terrain, and Methods are coming, but are not ready yet. The homepage shows their greyed-out previews.

## repo boundary

The site makes no runtime request for datafiles. Text extraction, analysis, and the much larger result archive are in the private repo `../the-zone`.
